# Chat Mate Landing Website

A mobile-responsive static landing page for Chat Mate with a direct APK download button.

## APK link
The download buttons point to:
https://huggingface.co/chatmateofficial/chatmateapp/resolve/main/app-release.apk

## Publish free with GitHub Pages
1. Open https://github.com/new and create a **public** repository, for example `chatmate-website`.
2. Upload `index.html` to the repository root (top level) and commit the changes.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes and refresh the Pages settings. Tap **Visit site** to open the website.

GitHub's official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Important
- The website can be published for free, but this ZIP does not publish it automatically; you must upload the file to your GitHub repository.
- Before sharing widely, test the APK URL on a phone and confirm it downloads the current signed release.
- This is a static site and does not include login, server-side code, analytics, or a backend.
